# Source PDFs

`docs/` is the canonical folder for locally supplied research PDFs:

- `anglo.pdf` — Carroll Quigley, The Anglo-American Establishment
- `scott.pdf` — Peter Dale Scott, The State, the Deep State, and the Wall Street Overworld
- `yankee.pdf` — Carl Oglesby, The Yankee and Cowboy War
- `TragedyAndHope.pdf` — Carroll Quigley, Tragedy and Hope

Source metadata in `src/data/archive.json` records each PDF’s checksum, file-page convention and coverage. Original PDFs remain local inputs; page-cited digests and narratives are the website’s static assets. Keep one copy of each PDF here. The former `sources/` copy of Anglo-American Establishment was identical to `anglo.pdf` and has been removed.
